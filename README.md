# Skybound Sprint

横向き画面で遊ぶ、ジャンプ操作のランニングゲームです。全3ステージを走り切り、**20000ポイント**を目指します。

## 遊び方

- スマートフォンは横向きにしてプレイします。画面をタップするとジャンプし、空中でもう一度タップすると2段ジャンプします。
- パソコンでは `Space`、`↑`、`W` のいずれかでジャンプします。空中でもう一度押すと2段ジャンプします。
- 障害物や穴を避け、コインを集めてスコアを伸ばします。スコアは走行距離とコイン（1枚100ポイント）の合計です。
- 画面右下の `Ⅱ` で一時停止、`▶` で再開できます。パソコンでは `P` または `Esc` でも切り替えられます。`♪` で音声のオン・オフを切り替えます。
- ゲームオーバー時は残りのリトライ回数だけ、そのステージの最初から再挑戦できます。全3ステージを終えた時点で20000ポイント以上なら目標達成です。

## ローカルで起動

`npm install` の後に `npm run dev` を実行し、表示された URL をブラウザで開いてください。
