# Current character resources

The game loads only these transparent 418px-cell sheets:

- `../../public/assets/characters/runner-girl-run-original-design.png`: eight run frames, 2×4, 12.5 fps.
- `../../public/assets/characters/runner-girl-jump-matched.png`: rising and falling jump poses, 1×2.

`runner-run-original-design/` retains the accepted source art, extraction script,
frames, loop preview and white-background contact sheet. `runner-jump-matched/`
retains the matching jump source, identity and pose references, frames and previews.
The white-background images are for review; the game uses transparent PNGs.

Obsolete run drafts and the previous mixed run/jump sheet were moved to macOS
Trash during cleanup. Prompts may mention those historical generation references;
they are not runtime dependencies. The current run and jump use the dark hair,
navy clothing and gray equipment approved in the latest game comparison.
